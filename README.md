De FANTAUZZO Maxime
et ROIG      Ghislain

Ce jeu réalisé dans le cadre du cours 
"Premier Projet d'Informatique" à l'Université de Liège.

-----------------------

Dans ce jeu, vous jouez un mineur tombé au fond d'une grotte. Vous n'avez aucun moyen de vous échapper.
Votre seule issue est de creuser jusqu'à ce que vous trouviez un moyen de vous en sortir.

Vous empaler contre les pics au plafond ou vous noyer dans la lave au fond de la mine
entrainera la fin de la partie.

------------------------

Commandes ;

Sur l'écran d'accueil, appuyer sur la barre espace pour lancer la partie.

Une fois en jeu :

- Flèche droite pour déplacer le mineur à droite
- Flèche gauche pour déplacer le mineur à gauche,
- Q sert à creuser le bloc de gauche,
- D sert à creuser le bloc de droite,
- S sert à creuser le bloc en dessous.

À tout moment, vous pouvez fermer le jeu en appuyant sur la touche Echap
et mettre en pause la partie en cours avec la touche P.

Si vous avez perdu, vous pouvez appuyer sur :
- la touche Y pour recommencer une partie ou sur 
- la touche N pour fermer le jeu.
